# Project Statement

## 1. Problem Statement

The project aims to develop a simple Flappy Bird-style game using Python. The player needs to control a bird and help it pass through gaps between moving pipes without colliding with them, the ground, or the ceiling.

The project provides a simple way to demonstrate basic programming concepts such as keyboard input, gravity, movement, collision detection, scoring, loops, functions, and random values in an interactive game.

## 2. Scope of the Project

The scope of this project includes developing a basic single-player Flappy Bird-style game using Python's Turtle library.

The project covers:

- Creating a graphical game window.
- Creating and controlling a bird.
- Applying a gravity effect to the bird.
- Creating moving pipes with randomly positioned gaps.
- Detecting collisions between the bird and obstacles.
- Maintaining and displaying the player's score.
- Displaying a game-over message when the bird collides with an obstacle or reaches the ground or ceiling.
- Providing keyboard-based control using the Spacebar.

The current project focuses on a simple desktop game and does not include features such as multiple players, online gameplay, sound effects, user accounts, or a high-score database.

## 3. Target Users

The project is mainly intended for:

- **Students** who are learning basic Python programming.
- **Beginners** who want to understand how simple games can be created using Python.
- **Teachers and instructors** who want a small practical project for demonstrating programming concepts.
- **Casual users** who want to play a simple, lightweight game.

## 4. High-Level Features

- **Interactive Game Window:** Provides an 800 × 600 game environment with a sky-blue background.
- **Bird Control:** The player can press the Spacebar to make the bird jump.
- **Gravity:** The bird continuously moves downward unless the player makes it jump.
- **Moving Pipes:** Green pipes move from right to left across the screen.
- **Random Pipe Gap:** The vertical position of the pipe gap is randomly generated.
- **Score System:** The player's score increases when the bird successfully passes a pipe.
- **Collision Detection:** The game detects collisions with the pipes, ground, and ceiling.
- **Game Over:** The game stops and displays a GAME OVER message after a collision.
